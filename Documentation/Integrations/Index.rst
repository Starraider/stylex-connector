.. _integrations:

============
Integrations
============

Complete :ref:`installation` first. These guides describe the changes needed
when a site uses a particular content or CSS system. They share the same
StyleX manifest and Vite entrypoint; none requires a second connector setup.

.. toctree::
   :maxdepth: 1

   ContentBlocks
   FluidStyledContent
   Bootstrap

Use :doc:`ContentBlocks` for custom or third-party Content Blocks. Use
:doc:`FluidStyledContent` when TYPO3's standard content elements provide
markup or CSS. Use :doc:`Bootstrap` for plain Bootstrap CSS or
``bk2k/bootstrap-package``. A project can follow more than one guide.
