================
StyleX Connector
================

:Extension key:
   stylex_connector
:Package name:
   skom/stylex-connector
:Version:
   1.0.0
:License:
   GPL-2.0-or-later
:Repository:
   https://github.com/Starraider/stylex-connector

StyleX Connector makes StyleX classes available in TYPO3 Fluid templates. A
sitepackage registers the JSON manifest created by its frontend build. The
``stylex:class`` ViewHelper then resolves semantic style keys such as
``Button.primary`` to the atomic CSS classes in that manifest.
